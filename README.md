# Password-strength-checker
This tool is built in python and is intended to be used to check password strength.

## Usage
```
python app.py

--- Password Strength Checker ---
Enter password to check: 
```
Enter the password and based on your input you will recieve:
```
Password is strong.
```
Or
```
Password is not strong!
Requirements: 8-32 chars, include Uppercase, Lowercase, Digit, and Special Char (@$#%!?&*._-).
```
